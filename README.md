# Sportmark 🏆

A responsive sports event ticket booking web application that allows users to explore sports events, view event details, and navigate through an interactive booking interface.

## 🚀 Features

- Browse available sports events
- View event details
- Select tickets through an interactive interface
- Smooth navigation between different sections
- Responsive design for desktop and mobile devices
- User-friendly interface

## 🛠️ Tech Stack

- React
- JavaScript
- HTML
- CSS
